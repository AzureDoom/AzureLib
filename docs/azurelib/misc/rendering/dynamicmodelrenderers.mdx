The **Dynamic Model Renderers** provide a flexible and extendable way to dynamically render 3D models in various Minecraft contexts. These renderers handle advanced rendering scenarios using **bone hierarchies**, **texture overrides**, and **render type customizations** to enable animations, dynamic updates, and customizable configurations for different entities, items, block entities, and armor.

## Common Functionalities Across Renderers

These renderers share a similar structure and core functionalities:

1. **Recursive Bone Rendering**:
   The core rendering process revolves around recursive rendering of bones and their hierarchies.

2. **Texture and Render Type Overrides**:
   Override textures and render types on a per-bone basis for more granular control over rendering.

### AzDynamicItemModelRenderer
This renderer is designed to handle dynamic rendering for item models. It supports advanced features like per-bone texture modifications and render type customizations.

#### Usage
1. **Create a Custom Renderer**:

   Extend the `AzDynamicItemModelRenderer`.

   Example:
   ```java
   public class YourModelRenderer extends AzDynamicItemModelRenderer {

       public YourModelRenderer(
               AzItemRendererPipeline itemRendererPipeline,
               AzLayerRenderer<ItemStack> layerRenderer
       ) {
           super(itemRendererPipeline, layerRenderer);
       }
   }
   ```

2. **Define Texture Overrides**:

   Implement `getTextureOverrideForBone`. This method allows you to set a specific texture for individual bones. For example, if a bone named `"dynamicbone"` requires a unique texture, you can return the proper texture file.

   Example:
   ```java
        protected final ResourceLocation DYNAMIC_ITEM_TEXTURE = ResourceLocation.fromNamespaceAndPath(
            YOUR_MOD_ID,
            "textures/item/dynamic_item_texture.png"
        );

        @Nullable
        @Override
        public ResourceLocation getTextureOverrideForBone(AzBone bone, ItemStack animatable, float partialTick) {
            // Provide a dynamic texture override for a specific bone
            return "dynamicbone".equals(bone.getName()) ? DYNAMIC_ITEM_TEXTURE : null;
        }
   ```

3.  **Define Render Overrides**:

   Implement `getRenderTypeOverrideForBone`. This method allows you to set a specific RenderType for individual bones. For example, if a bone named `"dynamicbone"` requires a unique RenderTYpe, you can return the proper RenderTYpe.

   Example:
   ```java
        @Override
        public @Nullable RenderType getRenderTypeOverrideForBone(
            AzBone bone,
            ItemStack animatable,
            ResourceLocation texturePath,
            MultiBufferSource bufferSource,
            float partialTick
        ) {
            return "dynamicbone".equals(bone.getName())
                ? RenderType.itemEntityTranslucentCull(texturePath)
                : null;
        }
   ```

4. **Assign the Model Renderer to your Item Renderer**:

   Register the custom model renderer for your renderer.

   Example:
   ```java
        @Override
        protected AzItemRendererPipeline createPipeline(AzItemRendererConfig config) {
            return new AzItemRendererPipeline(config, this) {
                @Override
                protected AzItemModelRenderer createModelRenderer(AzLayerRenderer<ItemStack> layerRenderer) {
                    return new YourModelRenderer(this, layerRenderer);
                }
            };
        }
   ```
