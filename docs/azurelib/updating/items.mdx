# Updating Items

A guide for converting GeckoLib 3 items to AzureLib on Forge 1.7.10.

| GeckoLib 3                                                          | AzureLib                                                                                |
|---------------------------------------------------------------------|-----------------------------------------------------------------------------------------|
| `IAnimatable` and `AnimationFactory` on the item                    | Removed. The item holds a Dispatcher instead                                            |
| `registerControllers` and predicates on the item                    | An `AzItemAnimator` class                                                               |
| `GeckoLibUtil.getControllerForStack` + `setAnimation` on the client | `AzCommand#sendForItem` from the server                                                 |
| `controller.registerSoundListener`                                  | `AzKeyframeCallbacks` on the controller builder                                         |
| `AnimatedGeoModel`                                                  | Model and texture go in `AzItemRendererConfig`, the animation file goes in the Animator |
| `GeoItemRenderer` + `MinecraftForgeClient.registerItemRenderer`     | `AzItemRenderer` + `AzItemRendererRegistry`                                             |

## Item Class

<CodeTabs>

```java !!tabs GeckoLib 3
public class ExampleItem extends Item implements IAnimatable {
    public AnimationFactory factory = new AnimationFactory(this);
    private String controllerName = "base_controller";

    private <P extends Item & IAnimatable> PlayState predicate(AnimationEvent<P> event) {
        // Not setting an animation here as that's handled in onItemRightClick
        return PlayState.CONTINUE;
    }

    @Override
    public void registerControllers(AnimationData data) {
        // Where you registered your Controllers and such
    }

    @Override
    public AnimationFactory getFactory() {
        return this.factory;
    }

    @Override
    public ItemStack onItemRightClick(ItemStack stack, World world, EntityPlayer player) {
        if (!world.isRemote) {
            return super.onItemRightClick(stack, world, player);
        }

        AnimationController<?> controller = GeckoLibUtil.getControllerForStack(this.factory, stack, controllerName);

        if (controller.getAnimationState() == AnimationState.Stopped) {
            controller.markNeedsReload();
            controller.setAnimation(new AnimationBuilder().addAnimation("firing", false));
        }
        return super.onItemRightClick(stack, world, player);
    }
}
```

```java !!tabs AzureLib
public class ExampleItem extends Item {
    // This is your class where you will setup the AzCommands/Animations you wish to play
    private final ExampleItemDispatcher dispatcher;

    public ExampleItem() {
        this.setMaxStackSize(1);
        // Create the instance of the class here to use later.
        this.dispatcher = new ExampleItemDispatcher();
    }

    @Override
    public ItemStack onItemRightClick(ItemStack stack, World world, EntityPlayer player) {
        if (!world.isRemote) {
            // This is where you now trigger an animation to play
            dispatcher.firing(player, stack);
        }
        return super.onItemRightClick(stack, world, player);
    }
}
```

</CodeTabs>

As you can see here, you no longer need to implement `IAnimatable`, keep an `AnimationFactory`, or look up controllers from the stack with `GeckoLibUtil`. Animations are now triggered on the **server** and synced to clients, so the `world.isRemote` check flips compared to GeckoLib 3. All that is needed now is a Dispatcher, which we will cover below.

## Animations

<Callout variant="info">
    See [here](../misc/animating/azcommands_101) for more indepth info about AzCommands
</Callout>

<CodeTabs>

```java !!tabs GeckoLib 3
    // In ExampleItem
    @Override
    public void registerControllers(AnimationData data) {
        AnimationController<ExampleItem> controller = new AnimationController<>(this,
            "base_controller", 20, this::predicate);
        controller.registerSoundListener(this::soundListener);
        data.addAnimationController(controller);
    }

    private <ENTITY extends IAnimatable> void soundListener(SoundKeyframeEvent<ENTITY> event) {
        // Play your sound
    }

    // In ExampleItemModel
    @Override
    public ResourceLocation getAnimationFileLocation(ExampleItem animatable) {
        return new ResourceLocation(YOUR_MOD_ID, "animations/exampleitem.animation.json");
    }
```

```java !!tabs AzureLib
public class ExampleItemAnimator extends AzItemAnimator {
    private static final ResourceLocation ANIMATIONS = new ResourceLocation(
        YOUR_MOD_ID,
        "animations/item/exampleitem.animation.json"
    );

    public ExampleItemAnimator() {
        super(AzAnimatorConfig.defaultConfig());
    }

    @Override
    public void registerControllers(AzAnimationControllerContainer<ItemStack> animationControllerContainer) {
        animationControllerContainer.add(
            AzAnimationController.builder(this, "base_controller")
                .setTransitionLength(20)
                // Replaces registerSoundListener; only needed if your animation has sound keyframes
                .setKeyframeCallbacks(
                    AzKeyframeCallbacks.<ItemStack>builder()
                        .setSoundKeyframeHandler(event -> {
                            EntityPlayer player = ClientUtils.getClientPlayer();

                            if (player != null && event.getKeyframeData().getSound().matches("firing")) {
                                player.worldObj.playSound(
                                    player.posX, player.posY, player.posZ,
                                    YOUR_MOD_ID + ":firing", 1.0F, 1.0F, false
                                );
                            }
                        })
                        .build()
                )
                .build()
        );
    }

    @Override
    public @Nonnull ResourceLocation getAnimationLocation(ItemStack animatable) {
        return ANIMATIONS;
    }
}
```

</CodeTabs>

<Callout variant="info">
    It is recommended to create a dedicated class for your animation triggers, as AzureLib works by sending animation commands rather than setting animations on a controller. This is the Dispatcher created in the item class above:
</Callout>
```java
public class ExampleItemDispatcher {
    private static final AzCommand FIRING_COMMAND = AzCommand.create(
        "base_controller",
        "firing",
        AzPlayBehaviors.PLAY_ONCE
    );

    public void firing(Entity entity, ItemStack itemStack) {
        FIRING_COMMAND.sendForItem(entity, itemStack);
    }
}
```

`addAnimation("firing", false)` maps to `AzPlayBehaviors.PLAY_ONCE`, and `addAnimation("firing", true)` maps to `AzPlayBehaviors.LOOP`.

## Rendering

<Callout variant="info">
    See [here](../misc/rendering/azrenderer_config#azitemrendererconfig) for a more indepth example
</Callout>

<CodeTabs>

```java !!tabs GeckoLib 3
public class ExampleItemModel extends AnimatedGeoModel<ExampleItem> {
    @Override
    public ResourceLocation getModelLocation(ExampleItem object) {
        return new ResourceLocation(YOUR_MOD_ID, "geo/exampleitem.geo.json");
    }

    @Override
    public ResourceLocation getTextureLocation(ExampleItem object) {
        return new ResourceLocation(YOUR_MOD_ID, "textures/item/exampleitem.png");
    }

    @Override
    public ResourceLocation getAnimationFileLocation(ExampleItem animatable) {
        return new ResourceLocation(YOUR_MOD_ID, "animations/exampleitem.animation.json");
    }
}

public class ExampleItemRenderer extends GeoItemRenderer<ExampleItem> {
    public ExampleItemRenderer() {
        super(new ExampleItemModel());
    }
}
```

```java !!tabs AzureLib
public class ExampleItemRenderer extends AzItemRenderer {
    private static final ResourceLocation GEO = new ResourceLocation(
        YOUR_MOD_ID,
        "geo/item/exampleitem.geo.json"
    );

    private static final ResourceLocation TEX = new ResourceLocation(
        YOUR_MOD_ID,
        "textures/item/exampleitem.png"
    );

    public ExampleItemRenderer() {
        super(
            AzItemRendererConfig.builder(GEO, TEX)
                .setAnimatorProvider(ExampleItemAnimator::new)
                .build()
        );
    }
}
```

</CodeTabs>

The model class is gone. This is where you now register the ResourceLocation model and texture of your item, and where you register your ExampleItemAnimator.

<Callout variant="info">
    The display transforms (first person, third person, GUI and so on) are read from `assets/YOUR_MOD_ID/models/item/exampleitem.json`, the same display file Blockbench exports for the item.
</Callout>

## Registering

<CodeTabs>

```java !!tabs GeckoLib 3
@SideOnly(Side.CLIENT)
public static void registerRenderers(FMLInitializationEvent event) {
    MinecraftForgeClient.registerItemRenderer(ItemRegistry.EXAMPLE_ITEM, new ExampleItemRenderer());
}
```

```java !!tabs AzureLib
// In your ClientProxy#init
@Override
public void init() {
    // This also registers the Forge IItemRenderer for the item for you
    AzItemRendererRegistry.register(ItemRegistry.EXAMPLE_ITEM, ExampleItemRenderer::new);
}
```

</CodeTabs>

Now simply call `AzItemRendererRegistry#register()` in your client proxy's init. Note that the item comes first and the renderer factory second, and you no longer call `MinecraftForgeClient.registerItemRenderer` yourself.

## Registering your Item for proper animation triggering

To ensure trigger animations work properly, you will need to also call `AzIdentityRegistry#register()` during `FMLInitializationEvent` in your common code (so it runs on both the client and the server) like so:

```java
AzIdentityRegistry.register(ItemRegistry.EXAMPLE_ITEM, ...);
```
