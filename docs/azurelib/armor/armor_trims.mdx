# Armor Trims

AzureLib supports Minecraft's armor trim system through the `AzArmorTrimLayer` render layer. It draws the trim on your custom armor model using the trim's pattern and the trim material's colors.

<Callout variant="info">
    This page is for Minecraft 1.20.1.
</Callout>

## How Trim Textures Work

A trim texture is a **grayscale** image. You register it in Minecraft's `armor_trims` atlas, and the atlas creates one colored copy per trim material (gold, iron, diamond, ...) using that material's palette. Each copy is named after the texture plus the material, for example `yourmod:armor/trim/your_armor_trim_gold`.

- Draw your trim with the same gray shades vanilla's trim textures use, so every shade maps to a material color.
- Texture ids are relative to `textures/` and have no `.png`: `yourmod:armor/trim/your_armor_trim` means `assets/yourmod/textures/armor/trim/your_armor_trim.png`.

## Implementation Approaches

### Approach 1: Single Texture for All Patterns

Uses one trim texture for every pattern, still colored by the trim material. Recommended when you don't have time to make a texture for every pattern.

#### Required Assets

1. **Create the trim texture**
   ```
   src/main/resources/assets/yourmod/textures/armor/trim/your_armor_trim.png
   ```

2. **Register it in the armor trims atlas**
   ```
   src/main/resources/assets/minecraft/atlases/armor_trims.json
   ```
   Example:
   ```json
   {
     "sources": [
       {
         "type": "paletted_permutations",
         "textures": [
           "yourmod:armor/trim/your_armor_trim"
         ],
         "palette_key": "trims/color_palettes/trim_palette",
         "permutations": {
           "quartz": "trims/color_palettes/quartz",
           "iron": "trims/color_palettes/iron",
           "gold": "trims/color_palettes/gold",
           "diamond": "trims/color_palettes/diamond",
           "netherite": "trims/color_palettes/netherite",
           "redstone": "trims/color_palettes/redstone",
           "copper": "trims/color_palettes/copper",
           "emerald": "trims/color_palettes/emerald",
           "lapis": "trims/color_palettes/lapis",
           "amethyst": "trims/color_palettes/amethyst",
           "iron_darker": "trims/color_palettes/iron_darker",
           "gold_darker": "trims/color_palettes/gold_darker",
           "diamond_darker": "trims/color_palettes/diamond_darker",
           "netherite_darker": "trims/color_palettes/netherite_darker"
         }
       }
     ]
   }
   ```
   Atlas files from every mod are merged, so this only adds your textures. It doesn't replace vanilla's.

#### Code Implementation
```java
public class ExampleArmorRenderer extends AzArmorRenderer {
    private static final ResourceLocation GEO = new ResourceLocation(
        YOUR_MOD_ID,
        "geo/item/examplearmor.geo.json"
    );

    private static final ResourceLocation TEX = new ResourceLocation(
        YOUR_MOD_ID,
        "textures/item/examplearmor.png"
    );

    public ExampleArmorRenderer() {
        super(AzArmorRendererConfig.builder(GEO, TEX)
            .addRenderLayer(new AzArmorTrimLayer(
                new ResourceLocation(YOUR_MOD_ID, "armor/trim/your_armor_trim"),
                false  // supportPatterns = false for a single texture
            ))
            .build());
    }
}
```
The layer looks up `your_armor_trim_<material>`, e.g. `your_armor_trim_gold`.

   ```json
     "yourmod:armor/trim/your_armor_shaper",

     "yourmod:armor/trim/your_armor_raiser",
     "yourmod:armor/trim/your_armor_host"
   ]
   ```

#### Code Implementation
```java
public ExampleArmorRenderer() {
    super(AzArmorRendererConfig.builder(GEO, TEX)
        .addRenderLayer(new AzArmorTrimLayer(
            new ResourceLocation(YOUR_MOD_ID, "armor/trim/your_armor")
            // supportPatterns defaults to true
        ))
        .build());
}
```
The layer looks up `your_armor_<pattern>_<material>`, e.g. `your_armor_coast_gold`.

## Advanced Usage

### Custom Texture Location Function
Pass a function to pick the atlas sprite for each trim yourself. It must return the **full** sprite name, including the material suffix the atlas adds:
```java
.addRenderLayer(new AzArmorTrimLayer(
    new ResourceLocation(YOUR_MOD_ID, "armor/trim/base"),
    trim -> {
        var pattern = trim.pattern().value();
        var material = trim.material().value();
        return new ResourceLocation(
            YOUR_MOD_ID,
            "armor/trim/custom_" + pattern.assetId().getPath() + "_" + material.assetName()
        );
    }
))
```
This is also where you can pick a darker variant, for example a gold trim on gold armor using `_gold_darker` so it stays visible, as long as that permutation is listed in your atlas file.

## Important Notes

- **Custom Textures Required**: Vanilla trim textures are made for the vanilla armor model's UV layout, so they won't line up with custom armor models.
- **Atlas Registration**: Every trim texture must be registered in the `minecraft:armor_trims` atlas.
- **Entity Required**: Trims are read from the item with the wearer's registries, so the layer only draws trims on armor worn by an entity.
- **Material Colors**: Colors come from each material's palette in the atlas `permutations`, so a material that isn't listed there has no sprite to render.

## Troubleshooting

### Trims Not Appearing
- Check that your trim textures are registered in `armor_trims.json`.
- Check that the texture paths match exactly between your atlas file and `AzArmorTrimLayer`.
- Ensure you're testing with items that have a trim applied.

### Wrong Colors
- Check that the material's palette is in your atlas `permutations`.
- Check that your texture uses the gray shades vanilla's trim textures use. Shades not in the palette won't be recolored.
