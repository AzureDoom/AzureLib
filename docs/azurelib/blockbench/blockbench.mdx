# How to install the Blockbench Plugin

To install the AzureLIb Blockbench Plugin, follow these steps:

Start Blockbench and open the file File menu in the top left corner.

![FileMenu](https://i.imgur.com/Y1LmXuz.png)


Select Plugins... to open the built-in plugin browser.

![Plugins](https://i.imgur.com/jzbdLUA.png)


Make sure you are in the Available tab, then search for the plugin: AzureLib Animator.

![Search](https://i.imgur.com/4nPgyUt.png)


Once you have found it, press the Install button on the right-hand side.

![Install](https://i.imgur.com/wJyZKvo.png)


You are now done!

![Installed](https://i.imgur.com/0k96ubQ.png)

You will now see the AzureLib Animated Model format in your Minecraft formats for projects.

![Installed](https://i.imgur.com/ilLi95I.png)
